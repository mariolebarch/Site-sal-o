# Como adicionar as fotos reais do Instagram

Este ambiente não conseguiu baixar as fotos do Instagram automaticamente
(o Instagram bloqueia esse tipo de acesso automatizado). Por isso, o site
usa ilustrações como espaço reservado até que as fotos reais sejam adicionadas.

Basta colocar os arquivos de imagem nesta pasta (`public/images/`) com
exatamente os nomes abaixo. Assim que o arquivo existir, a foto aparece
automaticamente no site — não é preciso alterar nenhum código.

| Nome do arquivo esperado      | Onde aparece                                  |
|--------------------------------|------------------------------------------------|
| `rosely-perfil.jpg`            | Foto de perfil da Rosely na home (topo)        |
| `rosely-atelie.jpg`            | Foto da Rosely trabalhando, seção "Sobre"      |
| `trabalho-destaque-1.jpg`      | Foto de destaque ao lado do "Sobre"            |
| `galeria-1.jpg` até `galeria-8.jpg` | Galeria de trabalhos (portfólio)          |

Dicas:
- Use fotos na proporção retrato (vertical) para melhor encaixe.
- Prefira arquivos `.jpg` ou `.png` com bom recorte e boa iluminação.
- Escolha as fotos com mais curtidas/melhor qualidade do
  @studioroselebarch para a galeria.
